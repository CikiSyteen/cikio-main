## 为什么用 MDX？

MDX 是 Markdown 的一种特殊形式，支持内嵌 JavaScript 与 JSX 语法。这让你可以[在 Markdown 内容中混用 JavaScript 和 UI 组件](https://docs.astro.build/en/guides/markdown-content/#mdx-features)，例如做交互式图表或提示框。

如果你已经有现成的 MDX 内容，这个集成应该能让迁移到 Astro 变得很轻松。
